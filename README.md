# ORYO

Веб-барнома барои кашидани нақша ва схемаҳо бо андозаҳои дақиқ. Як саҳифаи статикӣ аст: сервер, база ва насб лозим нест.

## Файлҳо

| Файл | Вазифа |
| --- | --- |
| `index.html` | Тамоми барнома (HTML, CSS, JavaScript) |
| `manifest.webmanifest` | Барои «Ба экрани асосӣ илова кардан» ва кушодан ҳамчун барнома |
| `sw.js` | Баъд аз боргирии аввал бе интернет кор мекунад |
| `icon.svg`, `icon-192.png`, `icon-512.png`, `icon-maskable-512.png` | Нишонаҳои барнома |

Ҳамаи файлҳо бояд дар як папка бошанд.

## Санҷиши маҳаллӣ

```
cd studio-web
python3 -m http.server 8080
```

Баъд `http://localhost:8080` -ро дар браузер кушоед. Файли `index.html`-ро бо дубора пахш кардан (`file://`) кушодан мумкин аст, аммо ҳолати оффлайн ва насби барнома кор намекунад. Барои онҳо сервер лозим аст.

## Гузоштан ба интернет

Ҳар як хостинги статикӣ мувофиқ аст. Суроға бояд бо **HTTPS** оғоз шавад, вагарна service worker ва насби барнома кор намекунанд.

- **Netlify**: ба netlify.com/drop даромада, папкаи `studio-web`-ро кашида гузоред.
- **Cloudflare Pages**: «Create project», «Direct upload», папкаро бор кунед.
- **GitHub Pages**: файлҳоро ба репозиторий андозед, дар Settings, Pages шохаи `main` ва папкаи `/ (root)`-ро интихоб кунед.
- **Сервери худӣ** (nginx, Apache): папкаро ба директорияи сайт нусха кунед.

## Чӣ тавр кор мекунад

- Лоиҳаҳо дар `localStorage`-и браузер нигоҳ дошта мешаванд. Маълумот ба ягон сервер намеравад.
- Ҳар домен ва ҳар браузер маълумоти худро дорад. Лоиҳаҳо байни дастгоҳҳо ё браузерҳо намегузаранд. Барои интиқол «Содир кардан», JSON-ро истифода баред.
- Агар маълумоти браузер (cookies ва сайт) тоза шавад, лоиҳаҳо нест мешаванд. Нусхаи эҳтиётӣ (JSON ё SVG) нигоҳ доред.
- Содир кардан: SVG, PNG, JSON, PDF (A4, бо масштаб) ва PDF-и ҳамаи ошёнаҳо.

## Китобхонаҳои беруна

- Шрифти **Noto Sans** аз Google Fonts. Агар бор нашавад, шрифти системавӣ истифода мешавад.
- **jsPDF 2.5.1** аз cdnjs.cloudflare.com барои PDF. Бе он PDF сохта намешавад, дигар чизҳо кор мекунанд.

Агар хоҳед, ки ба ҳеҷ сервери беруна вобаста набошад, `jspdf.umd.min.js`-ро дар папка гузошта, дар `index.html` тегро ба `src="jspdf.umd.min.js"` иваз кунед ва номашро ба `ASSETS` дар `sw.js` илова кунед.

## Навсозӣ

Баъд аз ивази файлҳо дар `sw.js` қимати `VERSION`-ро иваз кунед (масалан `studio-rasm-v2`), то браузерҳо кэши кӯҳнаро тоза кунанд.

## Идоракунӣ

- Телефон: ду ангушт калон ва ҷойивазкунӣ мекунад.
- Компютер: чархи мушак калон мекунад, `Del` хориҷ мекунад, `Ctrl+Z` / `Ctrl+Y` бекор ва такрор, `Ctrl+D` нусха, `Enter` анҷоми хат, `Esc` бекор, тирчаҳо объектро ҷойивазкунӣ, `Space` + кашидан барои ҷойивазкунии экран.
